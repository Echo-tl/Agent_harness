# Academic Paper Review

## 适用
用户给出一篇具体论文（arXiv 链接、题目、DOI）并要"review / 审稿 / 评价 / 总结"时使用。
多篇论文的横向综述请交给 systematic-literature-review。

## 流程

### 1. 读论文（用本项目的检索器）
- 有 arXiv 链接/ID → 用 `search` 或 arxiv 检索器拿到摘要；能抓取到全文更好。
- 逐节读：摘要与引言（贡献与动机）→ 相关工作 → 方法 → 实验/结果 → 讨论与局限 → 结论。

### 2. 提取关键论断
逐条列出论文的核心论断与支撑证据，评估证据强度（强/中/弱）。

### 3. 方法评估
| 维度 | 问题 | 评分 1-5 |
|------|------|:---:|
| 合理性 | 方法在技术上是否正确、有无逻辑缺陷 | |
| 新颖性 | 真正的新贡献 vs 增量改进 | |
| 可复现性 | 细节是否足够复现、有无代码/数据 | |
| 实验设计 | 基线是否公平、消融是否充分、数据集是否合适 | |
| 统计严谨 | 是否报告显著性、误差线、多次运行 | |
| 可扩展性 | 是否讨论计算成本与规模 | |

### 4. 贡献评估
按"开创性 / 重要 / 中等 / 边际 / 低于门槛"定级，并说明理由。

### 5. 强弱项与建议
- 每条强弱项给出：具体观察 + 位置（章节/图/表）+ 为什么重要。
- 建议必须是**可执行的**，禁止空泛批评（"写得差"没有用；要指出哪一节缺什么）。
- 至少要给 3 条强项、3 条弱项。

### 6. 输出结构
```
# Paper Review: <标题>
## 元信息（作者/venue/年份/领域/类型）
## 执行摘要（总体评价放最前面）
## 贡献列表
## 强项 S1/S2/S3...
## 弱项 W1/W2/W3...
## 方法评估表（上表）
## 给作者的问题
## 文献定位（与 SOTA 的关系）
## 结论：接受/弱接受/边界/弱拒/拒 + 置信度
```

## 原则
- 评价论文本身，不是评价作者/机构。
- 基于证据，给具体可执行建议。
- 保密：不泄露未发表内容。
