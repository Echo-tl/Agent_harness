# Systematic Literature Review

## 目标

产出跨多篇论文/来源的**综述**，而不是来源清单。报告必须做主题综合，让读者一眼看出领域里大家在做什么、共识是什么、分歧在哪、还缺什么。

## 流程

### 1. 界定范围
- 明确主题、要覆盖的来源数、时间窗口（如有）、引用格式（APA / IEEE / BibTeX，默认 APA）。
- 数量要克制：综述质量随数量增长快速下降，来源太杂时明确说明并建议拆分。

### 2. 检索（本项目的检索器）
- 用 `search` 搜主题 + `arxiv` 检索器找论文。查询用 2-3 个核心关键词，别把整句描述塞进查询。
- 学术类问题优先 arxiv；综合类问题用 web 搜索。
- 关键词不够时换措辞再搜，但**最多 2-3 轮**，避免无限重试。

### 3. 提取每条来源的要点
对每条来源记录：
- 标题 / 作者 / 日期 / 来源 URL
- 研究问题（一句）
- 方法（1-2 句）
- 关键发现（3-5 条要点）
- 局限（作者自述或明显缺失）
- 对应的证据 URL（必须真实存在，禁止编造）

### 4. 综合（报告的核心）
跨全部来源做主题分析，至少给出：
- **主题**：3-6 个反复出现的研究方向 / 方法 / 问题框架
- **共识**：多篇一致同意的结论
- **分歧**：结论矛盾或方法不兼容之处
- **空白**：现有文献尚未覆盖的方向

如果来源太少或太杂不足以支撑主题综合，**明确说出来**，不要硬造主题。

### 5. 引用格式
按用户要求读取对应模板（references/apa.md / ieee.md / bibtex.md），严格按其规则做文中引用与参考文献列表。每一条关键论断都要有可点击、可校验的来源链接。

## 常见错误
- ❌ 把报告写成"论文 1 讲了 A，论文 2 讲了 B"的流水账
- ❌ 没有识别共识 / 分歧 / 空白
- ❌ 编造来源 URL
- ❌ 引用格式混用
